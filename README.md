# 🎩 QWX MAFIA — мафия онлайн в 3D (браузер)

Клуб «Мафия» в той же нуарной стилистике, что QWX POKER и QWX BILLIARD: круглый стол под низкой лампой, люди в костюмах и шляпах, карты ролей рубашкой вверх.
Отдельная игра со своим сервером, своими аккаунтами и фишками.

## Что внутри
- **6–12 игроков, только люди.** Роли: Дон, Мафия, Комиссар, Доктор, Любовница (с 7 игроков), Мирные. Мафии: 2 на 6–7, 3 на 8–10, 4 на 11–12.
- **Ночь**: мафия выбирает жертву (ничья — решает Дон), Дон ищет комиссара, комиссар проверяет, доктор лечит (одного — не две ночи подряд, себя — раз за игру), любовница блокирует ход и защищает того, к кому пришла.
- **День**: обсуждение (чат + голос), кнопка «Готов», голосование, переголосование при ничьей, последнее слово. Роль выбывшего раскрывается.
- **Победа**: город — вся мафия поймана; мафия — её не меньше, чем мирных. **Взнос фишками**: банк делит вся победившая команда.
- **Чаты**: общий, тайный чат мафии ночью, чат выбывших. **Голос**: WebRTC, ночью слышат друг друга только мафиози, на последнем слове — только осуждённый.
- **3D-зал** (three.js): день/ночь светом, луна в окне, флип карт, выстрел, подсветка целей. **2D-стол** — лёгкий вид сверху.
- Клуб как в покере: вход через Telegram, колесо фортуны, сезонный пропуск, магазин (образы и рубашки карт), переводы по @username, топ месяца, рефералы, админ-панель со статистикой, переподключение, установка на телефон.

## Запуск
```
npm install
npm run build
npm start            # http://localhost:3000
npm test             # проверки ролей, ночи, голосования и целой партии с ботами
```

## Переменные окружения (Amvera → «Переменные»)
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_NAME` — бот для входа (свой, отдельный от покера и бильярда)
- `ADMIN_USERNAMES` — ваш Telegram username без @ (админ-панель; там же «Посадить ботов» для проверки)
- `DATA_DIR=/data` — уже задан в Dockerfile
- `TURN_URL`, `TURN_USER`, `TURN_PASS` — необязательно: свой TURN-сервер, если у части игроков голос не соединяется (строгий NAT у мобильных операторов)
